# Support and bug reports

Orbit Navigator is currently an early open-source project. Ordinary defects
should use the repository's structured
[Bug report](https://github.com/TheArranger/Orbit-Navigator/issues/new?template=bug_report.yml)
issue form.

Before reporting:

1. Confirm the issue occurs on the newest release.
2. Record the Orbit version and Windows version.
3. Write minimal reproduction steps, expected behavior, and actual behavior.
4. Use a test page or redact site-specific information where possible.
5. Review every screenshot and log for personal or browsing information.

Orbit does not automatically collect or upload diagnostics. Do not post
passwords, tokens, cookies, private-window activity, browsing history, page
contents, account identifiers, or sensitive local paths.

Security vulnerabilities must use the private process in `SECURITY.md`.

If Orbit Navigator is useful to you, the verified optional donation page is
[Ko-fi.com/paradoxthecreator](https://ko-fi.com/paradoxthecreator). Project and
maintainer work is also collected at [iamtheparadox.com](https://iamtheparadox.com/).
Neither link contains a tracking query, and donations never unlock required
security fixes or preferential vulnerability handling.

The verified public destination for a future in-app “Report a problem” link is
the structured Bug report URL above. Product wiring and release verification
remain separate from establishing this support endpoint.
